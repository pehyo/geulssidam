# 글씨담 (Geulssidam)

작성 가이드 PDF에서 손글씨를 추출해 TTF를 만드는 로컬 우선 Next.js 앱입니다. ver8-2350(2,350자 직접 글리프)과 ver9-jamo(자모 조합)를 하나로 합쳐, ver8처럼 화면에서 방식을 골라 쓸 수 있게 한 버전입니다.

## 모드

- **자모 조합**: 초성·중성은 한 칸에 하나씩, 받침은 "각"처럼 실제 글자로 쓰고, 몇 개의 조합 글자로 배치를 학습해 한글 음절 11,172자와 호환 자모를 조합합니다. 가이드는 6열 × 8행 격자입니다.
- **2,350자 직접 글리프**: KS X 1001 상용 한글 2,350자를 모두 직접 써서, 쓴 모양 그대로 글리프로 변환합니다. 가이드는 8열 × 12행 격자, A4 25쪽입니다.

두 모드는 가이드 격자와 칸 좌표가 다르므로, 고른 모드에서 내려받은 가이드로 작성한 PDF만 그 모드에 올려야 합니다. 모드를 바꾸면 선택한 파일과 추출 결과가 초기화됩니다.

## 실행

Node.js 20.9 이상:

```bash
npm install
npm run dev
```

`http://localhost:3000`을 엽니다. 배포 빌드는 `npm run build`, 실행은 `npm start`입니다.

## 사용 순서

1. 방식을 고르고 가이드 PDF를 다운로드합니다.
2. 안쪽 글자 영역의 약 70-85%를 채워 쓰고, A4 크기와 페이지 순서를 유지해 PDF로 만듭니다.
3. PDF를 업로드해 추출 및 누락 검사를 실행합니다.
4. 누락이 0이면 폰트 이름을 입력합니다.
   - 자모 조합: "배치 분석 · 폰트 생성"을 누르고 미리보기를 확인한 뒤 TTF를 다운로드합니다.
   - 2,350자: 바로 TTF를 다운로드합니다.

모든 처리는 브라우저 안에서 이루어지며 PDF는 서버로 업로드되지 않습니다.

## 구조

- `app/page.tsx`: 모드 선택과 공통 화면(가이드 → 추출 → 폰트)
- `lib/direct/`: ver8-2350의 2,350자 직접 글리프 구현. 가이드·칸 좌표는 그대로이고, 이진화 전 흐림(`extract.ts`)과 윤곽 추적·TTF 쓰기(`font.ts`)는 `lib/jamo`의 것을 함께 써서 저해상도 PDF에서도 픽셀 계단이 남지 않게 했습니다.
- `lib/jamo/`: ver9-jamo의 `lib`를 옮긴 자모 조합 구현

각 모드의 구현 설명은 원본 폴더(`ver8-2350`, `ver9-jamo`)의 README를 참고하세요.
